AL-FALAKIY STORE: SETUP
1. Create a free project at supabase.com.
2. SQL Editor: open setup.sql, change owner@example.com to your email, paste and Run.
3. Authentication > Users > Add user: use that same email and a strong password (tick Auto Confirm).
4. Authentication > Sign In / Providers > Email: turn OFF "Allow new users to sign up".
5. Project Settings > API: copy the Project URL and the anon public key into config.js.
6. Upload ALL files (index.html, admin.html, config.js, seed.js) to your GitHub repository.
7. Open yoursite/admin.html, log in, tap "Import my starter products", then add products anytime.
